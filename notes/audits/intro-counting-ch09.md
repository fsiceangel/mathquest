# Counting chapter 9: full variant difficulty review

2026-09-22: all 32 base stems and **96 variant stems** compared; nontrivial relative-order independence, restart, extended-series, twin-team, first-special-card adjacency and knockout routes inspected.

Several variants no longer need the base problem's main method: 9.2 #10 round 3 only ignores neutral sectors (L3 bridge), and worksheet #8 round 4 is a finite alternating-string complement (L3 bridge). These no longer inherit indefinite-game extension scope. First-round pairing, a last red ball, same-color first two draws, consecutive triples and first-round non-ties also have lower demands. Conversely, linked order conditions, asymmetric stopping thresholds and an unknown die size need additional reasoning and now have explicit L4 entries.

The first-special-card adjacency problems retain L4: removing one named object and reinserting it in equally likely gaps is a real insight, even when the final fraction is simple. The arbitrary number of neutral cards does not justify a naive remaining-card denominator. Inspected solutions use the valid gap construction. Infinite parity and alternating-turn problems retain optional extension scope. No definite key error established; all stems were read, but not every equivalent key was independently proved or checked against original textbook pages.
