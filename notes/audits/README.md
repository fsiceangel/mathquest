## 评分与 gap 的含义

L1 是直接识别/单步应用；L2 是短转换或常规模型；L3 是组合已学方法或逆向建模；L4 需要选法、辅助构造、非平凡分类；L5 是较长探索或较难组合。这不是实测的做题时间表。大数字、复杂符号或书的章号不自动增加等级。

每个母题有明确评分。变式有两种已审状态：`variant-reviewed` 表示显式记录单题等级/范围/理由；`variant-equivalent` 表示本章全部变式题干已比较后，保留母题评级。`inherited` 表示未完成复核，发布检查会拒绝它。

页面先选择本轮题目，再进行稳定难度排序。源数组不改，原题目、答案、轮次和进度 ID 保留。这样处理的是同一练习内部的先易后难，**不能自动补齐未教的方法**。

因此另外补了具体教学支架：第 7 章的追及/逆平均速度/工作速率，统计的数据构造，计数的受限分配/分类/条件概率，以及几何的坐标圆心例题。`bridges.js` 中的说明会在相关章节、worksheet 入口给出可点击的例题链接。

报告保留排序后仍缺级的组，不通过降低评级隐藏问题。机器汇总分别统计所有范围中的缺级、排除可选拓展后的主线缺级，以及已有完整例题支持的缺级。**有例题支持仍不等于教学上已经无障碍**；需要观察孩子是否能不看提示迁移到新题。

最终统计：317 组母题练习存在先难后易，现由展示排序处理。四轮合计仍有 11 组缺级，其中主线 4 组：Prealgebra 13 worksheet 第四轮、Counting 1 challenge 第三轮、Counting 5.4 第三轮、Counting 12.3 第三轮。四组均已补相应完整例题和入口链接；其余缺级涉及可选拓展。完整 gap 明细保留在 JSON 中。
