# Authoring notes

Working documents for whoever writes the next chapter. They are not part of the
site — nothing here is shipped or imported.

- **`base-chapter-spec.md`** — the shape of a base chapter file: how many
  concepts, examples and problems, how the difficulty ramps, and the house
  rules on conventions, distractors, figures and voice.
- **`variation-spec.md`** — how a base problem gets its three variations: the
  three lanes (fresh numbers, a different scenario shape, reversed or derived),
  the derived answer-index rule, key distinctness, and the two-route solution
  format the variations use.
- **`arena-spec.md`** — the calibration the four Arena papers were written to:
  five difficulty bands, ascending choices, a lane per slot so no two papers
  share a problem.
- **`checkpoint-spec.md`** and **`checkpoints/`** — the between-chapter papers:
  what a checkpoint is, where each one sits, its bands and quotas, and one lane
  table per book giving every slot's idea and twist.
- **`pins/`** — one file per chapter of Counting & Probability, written before
  any prose. Each pins the scenario and the answer for all 156 (or 216)
  variations, with every key brute-forced first. Authors write against the pin
  file; if their arithmetic disagrees with a pin, one of the two is wrong and it
  gets resolved rather than quietly retargeted.

The reason for the pin step: keys chosen while writing tend to collide, and a
chapter whose round 3 repeats round 2's answers teaches a student to guess. The
pins let the whole chapter's key layout be checked before a single problem is
written.
